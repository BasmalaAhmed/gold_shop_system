# نظام إدارة ومبيعات محلات الذهب الموحد (Gold Shop Unified App)

تطبيق فلاتر (Flutter) موحد وشامل يجمع الأنظمة الفرعية الخمسة لمحلات الذهب في مشروع واحد متكامل وقوي:

---

## 🏗️ الأقسام المدمجة في المشروع (Modules)

تم دمج وتنسيق المشاريع الخمسة التالية كحزم برمجية معيارية (Modular Architecture) داخل مجلد `lib/modules/`:

1. **المصادقة والجلسة والتحقق (`auth_notification`)**:
   - تسجيل الدخول الآمن، التحقق عبر رمز OTP، والتحقق من الجهاز الجديد.
   - إدارة الجلسات وتجديد التوكن التلقائي عبر التخزين الآمن (`flutter_secure_storage`).
   - استقبال وتنسيق روابط الاعتماد العميقة (Deep Links) عبر بروتوكول `myapp://approval/...`.

2. **نقطة البيع وبيع الذهب (`gold_sale`)**:
   - شاشة بيع متجاوبة للهواتف والأجهزة اللوحية (Mobile & Tablet Layouts).
   - أسعار الذهب اللحظية للشراء والبيع لعيار 18 و 21 و 24.
   - سلة المشتريات، ماسح الباركود بالكاميرا (`mobile_scanner`) أو الإدخال اليدوي.
   - حساب مصنعية الذهب، واستبدال الذهب القديم (ذهب كسر / Trade-in).
   - تطبيق الخصومات مع طلب موافقة المشرف عند تجاوز نسبة 10%.
   - الدفع المتعدد (نقداً، إنستاباي، فودافون كاش، بطاقات).

3. **تحصيل الديون والأقساط (`debts_payment`)**:
   - سجل حسابات ديون العملاء وجدولة الأقساط.
   - تسجيل عمليات السداد والتوزيع التلقائي على الأقساط المستحقة.
   - قاعدة بيانات محلية SQLite (`sqflite`) للعمل دون اتصال بالإنترنت (Offline-First).
   - مزامنة خلفية تلقائية فور عودة الاتصال بالإنترنت (`SyncWorker` & `SyncOnReconnect`).
   - شاشة طابور العمليات المعلقة وحالات المزامنة.

4. **إدارة واعتماد طلبات المتجر (`shop_approval`)**:
   - لوحة تحكم المشرف والمدير لاعتماد أو رفض العمليات الاستثنائية.
   - تصنيف الطلبات (قيد الانتظار، معتمدة، مرفوضة).
   - كشف التعارض والتحديث الخارجي في الوقت الفعلي.
   - تنبيهات حالة الاتصال وتحديث تلقائي للبيانات.

5. **مراقبة الفرع والعمليات الحية (`shop_monitoring`)**:
   - مؤشرات الأداء الحية (حجم المبيعات اليومية، رصيد الخزينة، حركة الذهب الصادر والوارد).
   - سجل العمليات والتحويلات اللحظية مع إمكانية التصفية.
   - التبديل السلس بين الفروع والمتاجر (`shop_1` / `shop_2`).
   - إدارة حالة التطبيق باستخدام `flutter_bloc` وحقن التبعيات بـ `get_it`.

## 📁 هيكلية المشروع (Project Architecture)

```text
gold_shop_unified_app/
├── android/               # إعدادات أندرويد مع أذونات الكاميرا والإنترنت والروابط العميقة
├── ios/                   # إعدادات iOS
├── web/                   # إعدادات الويب
├── windows/               # إعدادات تطبيق سطح المكتب لويندوز
├── assets/
│   └── fonts/
│       ├── Cairo/                 # خط كايرو بجميع الأوزان
│       └── IBM Plex Sans Arabic/  # خط آي بي إم بلكس العربي
├── lib/
│   ├── main.dart                  # نقطة الدخول الموحدة لتشغيل التطبيق
│   ├── app/
│   │   ├── unified_app.dart           # تطبيق MaterialApp الموحد مع MultiBlocProvider والتعريب
│   │   ├── auth_gate.dart             # بوابة التحقق (تسجيل الدخول / شاشات التحقق / الواجهة الرئيسية)
│   │   ├── main_shell.dart            # الشاشة الرئيسية الموحدة وشريط التنقل السفلي
│   │   └── unified_dependencies.dart  # تهيئة جميع قواعد البيانات والخدمات والاتصالات
│   ├── core/
│   │   └── unified_theme.dart         # الهوية البصرية الموحدة (ألوان ذهبية وكحلية عصرية)
│   └── modules/                       # الوحدات المدمجة من المشاريع الخمسة
│       ├── auth_notification/
│       ├── debts_payment/
│       ├── gold_sale/
│       ├── shop_approval/
│       └── shop_monitoring/
├── test/
│   ├── unified_app_test.dart
│   └── modules/                       # جميع اختبارات الوحدات الخمسة
│       ├── auth_notification/
│       ├── debts_payment/
│       ├── gold_sale/
│       ├── shop_approval/
│       └── shop_monitoring/
└── pubspec.yaml                       # ملف الحزم والتبعيات الموحد
```

## 🚀 كيفية التشغيل (How to Run)

1. افتح المشروع في محرر الأكواد (VS Code / Android Studio / Cursor).
2. قم بتحميل الحزم:
   ```bash
   flutter pub get
   ```
3. تشغيل التطبيق:
   ```bash
   flutter run
   ```
